# Arena

A small first-person duel game that runs in the browser. You against a bot, first to five rounds.

Play it at https://ajith.ai/arena/

- One file: `index.html`. Plain WebGL, no libraries, no build step, no tracking.
- The live copy is part of ajith.ai. Its source is in the [ajith.ai repo](https://github.com/ajithjoseph/ajith.ai) under `arena/`.
- Needs a keyboard and mouse.
